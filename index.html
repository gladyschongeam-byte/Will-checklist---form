📎 第二部分：遗嘱写好后，自己在家准备和保管的资料
这些资料不需要在立遗嘱时给律师，但要和遗嘱一起保管好。这是提醒你要准备什么，不需要直接填写。
✓ 重要资产文件的副本
• 屋契副本（photocopy）
• 车卡副本（photocopy）
• 银行账户：银行名称、账户号码
• 股票/投资基金证书副本
• 任何其他重要资产的证明副本
✓ 珠宝、古董、金器的证明资料
• 物品的照片（最好是清晰的多角度照片）
• 购买收据或鉴定证书
• 列出每件物品的清单，说明要留给谁
✓ 保险单
• 保险公司名称
• 保单号码
• 保单上指定的受益人是谁
• 人寿保险、医疗保险、车保，有的话都要列出
✓ 你的债务清单
• 房屋贷款：银行名称、还欠金额
• 汽车贷款：银行名称、还欠金额
• 信用卡债务：银行名称、还欠金额
• 其他贷款：比如向朋友借的钱、医疗债务等、还欠金额
✓ 联名或共同资产
• 哪些资产是联名的？
• 是什么类型的联名？（比如联名账户、共同房产）
✓ 账户信息和登录信息
这些密码可以放在只有受益人知道的地方：
• 电子邮件账户：邮箱地址、密码
• 网上银行：用户名、密码
• 社交媒体账户：Facebook、微信等的账号和密码
• 购物账户：Lazada、Shopee等
• 其他重要账户：PayPal、支付宝、车险、医疗平台等
✓ 执行人需要联系的人
• 你的律师：名字和电话号码
• （如果没有认识的律师，可以联系 Mr Loo 0183801719）
• 会计师/税务顾问
• 保险经纪人
• 其他关键人物：比如合伙人、房东等

如果你已经买了富贵山庄，或者有其他新的资产或计划，记得把它包括进遗嘱。
